# Orchestration Patterns

An orchestration pattern defines how work is distributed and coordinated. It
determines which roles participate, how tasks are sequenced or parallelized,
and how results are routed between workers.

Examples include:

- single-pass execution;
- pipelines;
- planner-worker systems;
- parallel search;
- best-of-N generation;
- debates;
- reviewer-implementer arrangements.

A pattern organizes the work. It does not by itself determine whether a result
is correct or whether another attempt is needed.
